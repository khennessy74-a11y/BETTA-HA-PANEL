# BETTA HA Panel Release Images

This folder contains packaged firmware produced by this fork of BETTA HA Panel.

## Supported variants

| Variant | Hardware | Current published factory image |
|---|---|---|
| `panel4` | Waveshare ESP32-P4-WIFI6-Touch-LCD-4B | [v0.9 panel4](https://github.com/khennessy74-a11y/BETTA-HA-PANEL/releases/download/V0.9/betta-ha-panel-v0.9-panel4.factory.bin) |
| `panel10` | Waveshare ESP32-P4 Module Nano + 10.1" DSI panel | [v0.9 panel10](https://github.com/khennessy74-a11y/BETTA-HA-PANEL/releases/download/V0.9/betta-ha-panel-v0.9-panel10.factory.bin) |
| `panels3` | Guition ESP32-S3-4848S040 | [v0.9 panels3](https://github.com/khennessy74-a11y/BETTA-HA-PANEL/releases/download/V0.9/betta-ha-panel-v0.9-panels3.factory.bin) |

The `v0.10-development` branch currently identifies itself as **v0.10-rc1**. CI artifacts from that branch are release-candidate builds for testing; they are not the published stable release until hardware validation is complete.

## Flashing

For a clean install or recovery, flash the matching `.factory.bin` at offset `0x0`.

For an already-configured panel, prefer the settings-preserving USB flash kit generated by CI when testing development builds. It intentionally avoids overwriting NVS.

For in-app updates, use the matching `.ota.bin` file from `release/ota/`.

The ESP32-P4 factory images include the required C6 network-adapter firmware.

## Packaging policy

The release version is read from `BETTAOS_RELEASE_VERSION` in the root `CMakeLists.txt`. GitHub Actions packages versioned factory and OTA images for all three hardware variants.

Older packaged images are retained under `release/archive/` and `release/ota/archive/` where applicable.
